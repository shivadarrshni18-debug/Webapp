# Web Application Boilerplate

This is a clean, framework-free boilerplate for a Web Application.

## Technologies Used

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Plain Java (No web frameworks)
- **Build Tool:** Gradle
- **Database:** MySQL

## Project Structure

- `/frontend`: Contains all UI assets (`index.html`, `css/`, `js/`).
- `/backend`: Contains the Java backend and Gradle build configuration.
- `/database`: Contains the `schema.sql` for MySQL table definitions.

## How to Run

### Backend

Navigate to the `backend` directory in your terminal:

1. **Build and test the backend:**
   ```bash
   gradle test
   ```
